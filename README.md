## Засах

Дэлгэрэнгүй зааврыг `ЗААВАР.txt`-ээс үзнэ үү.

**Текст:** `index.html` дотроос Ctrl+F-ээр хайж олоод солино.
UTF-8-аар хадгална.

**Өнгө:** 16–24-р мөрөнд бүх өнгө нэг дор байна.

```css
--red:#E02A26;    /* гол улаан */
--ink:#17110F;    /* үндсэн бичиг */
--paper:#FFFFFF;  /* дэвсгэр */
```

**Арын зураг:** зургаа энэ хавтсанд хийгээд 22-р мөрийг соль.

```css
--bg:url("bg.jpg");
--bg-veil:.88;    /* .95 бүдэг · .88 тэнцвэртэй · .70 тод */
```
