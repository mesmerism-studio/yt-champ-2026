ТЕКСТ ЗАСАХ ЗААВАР
==================

ЭНД ЮУ БАЙНА
------------
index.html    Сайт. Үүнийг засна.
logo.webp     Лого. Битгий устга, битгий нэрийг нь соль.

Хоёулаа НЭГ хавтсанд байх ёстой.


ЯАЖ ЗАСАХ ВЭ
------------
1. index.html дээр баруун товч -> Open with -> Notepad
   (Эсвэл VS Code, Notepad++ байвал түүгээр нээвэл илүү сайн)

2. Ctrl+F дараад солихыг хүсэж буй үгээ бич.
   Жишээ: "Гурван жил"

3. Тэр хэсгийн бичгийг л соль. Дараах шиг байдаг:

       <h2 data-split>Гурван жил. Арван нэгэн сая үзэлт.</h2>
                      ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
                      ЗӨВХӨН ЭНЭ ХЭСГИЙГ СОЛЬ

   < > хаалт доторх зүйлийг БИТГИЙ ГАР.

4. Ctrl+S дараад хадгал.
   (Notepad-д: File -> Save As -> Encoding "UTF-8" гэдгийг СОНГО!)

5. index.html дээр 2 удаа дараад браузераар нээ.
   Аль хэдийн нээлттэй бол Ctrl+F5 дараад сэргээ.

457   Танай брэнд хаана харагдах вэ.

Тоо, огноо, багцын үнэ бүгд мөн адил index.html дотор байгаа.
Ctrl+F -ээр хайж олоод солино.


АНХААРАХ
--------
- UTF-8 -ээр хадгал. Үгүй бол кирилл үсэг эвдэрнэ.
- < > хаалт, class="..." зэргийг битгий гар.
- Эргэлзвэл эхлээд файлаа хуулж аваад (backup) заса.

Засаад дуусвал надад хэлээрэй - интернэтэд тавьдаг нэг файл
болгож (лого дотор нь суусан) буцааж хийж өгье.


АРЫН ЗУРАГ ТАВИХ
================
1. Зургаа энэ хавтсанд хий (index.html-тэй хамт).
   Нэрийг нь  bg.jpg  гэж өгвөл хамгийн амар.

2. index.html дотор 22-р мөр:

       --bg:none;
   ->  --bg:url("bg.jpg");

3. Хадгалаад браузер дээр Ctrl+F5.

Зураг хэт тод байвал 26-р мөрийг тохируул:

       --bg-veil:.88;

   .95  = зураг бүдэг, бичиг тод   (аюулгүй)
   .88  = тэнцвэртэй               (санал болгож байна)
   .70  = зураг тод, бичиг уншихад хэцүү

Зураг нь бүх дэлгэцийг дүүргэж, гүйлгэхэд хөдөлдөггүй
(fixed) байхаар тохируулсан. 1920x1080-аас дээш хэмжээтэй
зураг тавьбал сайн.
